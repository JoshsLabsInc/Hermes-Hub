# Third-party components

Hermes Hub uses the Microsoft .NET Windows Desktop runtime and Microsoft .NET libraries, QRCoder, and BouncyCastle.Cryptography. QRCoder and BouncyCastle license texts are included under Assets/Licenses in the installed app. Preserve all runtime-provided license and third-party notice files shipped alongside the application. The public source project files identify the pinned package versions.

- .NET: https://github.com/dotnet/runtime/blob/main/LICENSE.TXT and bundled ThirdPartyNotices.txt.
- QRCoder 1.7.0, MIT: https://github.com/codebude/QRCoder/blob/master/LICENSE.txt
- BouncyCastle.Cryptography 2.7.0: https://www.bouncycastle.org/licence.html

Ollama and Qwen model weights are not bundled. Installation/model downloads are explicit user actions. Their license terms and hardware requirements apply independently. Third-party artwork, music or anime sound recordings are not added by this distribution update.

Before public release, complete the license/notice audit for every transitive package and select a license for JLabs source code. These references are an inventory, not a substitute for required license texts.
